# Production Portfolio

A responsive and accessible personal portfolio website developed for the Web Application Development course.

## Overview

This project demonstrates the implementation of a production-oriented portfolio website with a focus on:

- Semantic HTML structure
- Responsive layout
- WCAG 2.2 AA accessibility
- Keyboard accessibility
- Strict Content Security Policy (CSP)
- Performance optimization
- Clean and maintainable code

## Features

- Semantic landmark structure
- Skip-to-main-content accessibility link
- Responsive navigation
- Responsive project card grid
- Accessible contact form
- Keyboard-friendly interactions
- Strict Content Security Policy
- Optimized JavaScript loading
- Responsive design for different screen sizes

## Technologies

- HTML5
- CSS3
- JavaScript
- Git & GitHub

## Accessibility

The project follows accessibility practices including:

- Proper semantic landmarks
- A clear heading hierarchy
- A single primary `h1`
- Visible keyboard focus states
- Accessible form labels
- Skip navigation
- WCAG 2.2 AA contrast considerations
- Keyboard navigation support

## Security

A strict Content Security Policy is implemented to reduce security risks.

The project avoids:

- Inline JavaScript
- Inline event handlers
- Untrusted script sources
- Unnecessary external resources

## Performance

Performance improvements include:

- Deferred JavaScript loading
- Lightweight assets
- Responsive CSS Grid
- Reduced unnecessary client-side processing
